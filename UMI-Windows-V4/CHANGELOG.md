# Windows V4 更新记录

## 4.2.0 - 2026-08-25

- 三版本仓库合并和文档分层。
- 正式控制台入口统一为 `/index.html`，数据看板为 `/dashboard.html`。
- LeRobot 真实动作、任务、时间戳、IMU、终止标记和统计量校验。
- HDF5/RLDS 观察数据归档状态明确化。
- 清理重复 SDK、Windows 版本中的 Linux 库和未接入的旧夹爪试验代码。

## 4.1.2 - 2026-08-17

- 支持 Unicode 安装路径和非系统盘安装。
- 修复启动器假就绪、页面缺失和 Edge 打开失败问题。

## 4.1.1 - 2026-08-17

- 安装包内置相机、串口和 CAN 运行库及驱动。
- 内置 Python 和数据转换依赖。

## 4.1.0 - 2026-08-17

- 新增一键安装包。
- 优化设备稳定性、多相机 USB 带宽、会话保存和数据转换。

## 4.0.0 - 2026-06-27

- UMI V4.0 手动夹爪协议。
- 双手动夹爪、多相机、相机控制、夹爪交换和统一时间戳采集。

更早的项目演进见仓库根目录 [`CHANGELOG.md`](../CHANGELOG.md)。
