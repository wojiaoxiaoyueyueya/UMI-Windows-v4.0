# Windows V4 更新记录

## 4.3.2 - 2026-08-26

- 安装向导新增简体中文/English 选择，并强制显示安装目录页；用户可浏览非系统盘并新建安装文件夹。
- 桌面和开始菜单只保留一个启动入口；关闭最后一个平台网页后自动释放相机、串口和 CAN 并退出后台，异常关页回收缩短到约 15 秒，卸载时同样先安全释放设备。
- 修复缓慢移动时模型只旋转不平移：视觉光流补足低加速度运动的相对尺度，IMU 继续提供方向、重力和静止约束。
- 空间位姿页新增随夹爪同步运动的鱼眼相机模型、相机视锥和可选稀疏视觉特征点云。
- 按 STEP 几何把夹指单侧动画行程从 `35.5 mm` 修正为 `53.5 mm`，并将新版磁编码端点余量映射为完整闭合。
- 提高静止重力校正增益，继续抑制模型缓慢后仰；静止光流门限仍会冻结位置，避免点云噪声造成累计漂移。
- 精简安装包中的 Three.js 开发源码、PyArrow 头文件、导入库和 Cython 源码；保留离线运行脚本、许可证和完整转换能力。

## 4.3.1 - 2026-08-26

- 修复侧栏伸缩按钮在不同功能页位置错位的问题；按钮改为跟随当前页面实际侧栏边沿与高度定位，并适配收起动画、窄屏和独立数据看板。
- 修正静止模型因 V4 IMU 残余零偏而缓慢后仰的问题，加入每只夹爪独立的启动零偏学习和静止温漂补偿。
- 修正重力姿态反馈方向和位移积分顺序，启动及重置姿态统一为相对零姿态。
- 限制未标定鱼眼本质矩阵的姿态权重，静止和低光流画面不再持续累加伪旋转。
- 单手静止时独立执行零速度约束；缺少可信 IMU 位移尺度时不再由单目光流生成假距离。
- 新增初始画面特征锚点和原点重定位，拿起后放回相近视野并静止时自动消除闭环位置误差。
- 三维前端增加位置/姿态插值、轨迹写入死区和静止去抖；位姿 CSV 新增静止及原点重定位状态。

## 4.3.0 - 2026-08-26

- 新增左右手“空间位姿”页面，以独立视觉惯性跟踪器融合鱼眼画面和 V4 IMU，显示相对三维轨迹、姿态和跟踪质量。
- 导入完整手动夹爪 STEP 装配源文件，网页使用离线 GLB 模型，并按实时闭合度联动夹爪模型。
- 缩小三维模型并增加 `1×~8×` 轨迹显示倍率、动态取景、旋转/平移/缩放交互和完整闭合端点映射。
- 新增双手协同静止约束；双方视觉和 IMU 同时确认静止时执行零速度更新，降低静态轨迹漂移。
- 新增 `pose_data/trajectory.csv` 录制文件和双手位姿 REST API；摄像头及夹爪左右交换会同步到跟踪与保存映射，CSV 保存协同约束状态。
- 删除未接入主流程的旧 `SlamManager` 占位实现，三维前端改为离线 Three.js 单文件包。
- 总仓库迁移到浅层目录并清理旧驱动副本、日志、缓存和失效编辑器配置。
- 新增网页生命周期登记与心跳、最后页面关闭自动退出、120 秒异常回收、单实例保护和端口冲突退出。
- 安装版新增“退出 UMI 数据采集平台”快捷方式；启动器可识别并清理无响应旧后台，避免相机、串口、CAN 和 8080 端口被持续占用。

## 4.2.0 - 2026-08-25

- 三版本仓库合并和文档分层。
- 正式控制台入口统一为 `/index.html`，数据看板为 `/dashboard.html`。
- LeRobot 真实动作、任务、时间戳、IMU、终止标记和统计量校验。
- HDF5/RLDS 观察数据归档状态明确化。
- 清理重复 SDK、Windows 版本中的 Linux 库和未接入的旧夹爪试验代码。
