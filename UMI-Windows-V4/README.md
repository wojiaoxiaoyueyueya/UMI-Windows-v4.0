# UMI Windows V4 数据采集平台

`UMI-Windows-V4` 是当前推荐使用的 Windows 主版本，面向 UMI V4.0 手动夹爪、多相机数据采集和电动夹爪控制。

## 版本状态

| 项目 | 内容 |
| --- | --- |
| 当前版本 | `4.3.2` |
| 发布日期 | 2026-08-26 |
| 操作系统 | Windows 10 / Windows 11 64 位 |
| 手动夹爪协议 | UMI V4.0 |
| 后端 | C++14 本地 HTTP 服务 |
| 前端 | 原生 HTML / CSS / JavaScript |
| 默认端口 | `8080` |
| 默认安装目录 | `D:\UMIDataCapturePlatform` |

## 主要能力

- 海康工业相机、Orbbec Gemini 305 和浏览器 UVC 相机接入。
- 彩色、深度、双红外、点云、手动夹爪和电动夹爪数据采集。
- 双 UMI V4.0 手动夹爪识别、槽位交换、标定补偿、按键、IMU、LED 和参数读取。
- 相机曝光、增益、白平衡、Gamma、锐度、降噪和鱼眼显示控制。
- GCAN 或 ESP32-S3 CAN 串口桥控制电动夹爪。
- 剪刀石头布手势联动和手动夹爪遥控电动夹爪。
- 左右手视觉 + IMU 相对位姿、三维轨迹、夹爪 STEP 模型和闭合动画。
- 统一会话时间基准、历史记录、后台保存队列和会话删除。
- LeRobot、HDF5、RLDS 格式转换和训练就绪校验。
- 一键 Windows 安装包，内置运行时、SDK 和硬件驱动文件。
- 页面心跳、单实例和安全退出闭环，关闭最后一个页面后自动释放全部设备句柄。

## 支持设备

| 类型 | 当前适配 |
| --- | --- |
| 手动夹爪 | UMI V4.0 双手动夹爪 |
| 工业相机 | 海康 MVS USB 工业相机 |
| 深度相机 | Orbbec Gemini 305 |
| 手势相机 | IMX335 或其他 UVC 相机 |
| 电动夹爪 | CAN 电动夹爪，统一行程 `0°~4500°` |
| CAN 接口 | GCAN USBCAN、ESP32-S3 `can_transceiver` |

## 4.3.2 重点更新

- 安装界面支持简体中文与 English 切换，安装目录页可选择非系统盘并新建文件夹。
- 安装后只显示一个启动图标；关闭最后一个平台网页后约 3 秒自动释放全部设备并结束后台，浏览器异常关闭约 15 秒回收，不再要求手动点击退出图标。
- 低速移动时由视觉光流补足相对位移尺度，修复模型只在原地转动的问题；IMU 继续负责方向、重力和静止约束。
- 三维场景新增随夹爪同步运动的鱼眼相机、视锥和可开关的稀疏视觉特征点云。
- 按 STEP 几何修正夹指动画行程，并把 V4 磁编码端点余量映射到完整闭合。
- 安装包移除运行时不需要的开发源码和头文件，保留驱动、SDK、离线前端、Python 转换环境及许可证。

轨迹是视觉惯性估算的相对位姿，不是外部定位系统给出的绝对世界坐标。稀疏点云使用单目特征射线和名义工作距离展示特征分布，不是深度相机的真实测距点云。拿起后回到与重置时相近的视野并保持静止，系统会尝试重定位到原点；需要绝对定位时仍需完成内外参、硬件同步和外部基准标定。
