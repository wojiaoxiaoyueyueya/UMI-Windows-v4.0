# UMI Windows V4 数据采集平台

`UMI-Windows-V4` 是当前推荐使用的 Windows 主版本，面向 UMI V4.0 手动夹爪、多相机数据采集和电动夹爪控制。

## 版本状态

| 项目 | 内容 |
| --- | --- |
| 当前版本 | `4.3.1` |
| 发布日期 | 2026-08-26 |
| 操作系统 | Windows 10 / Windows 11 64 位 |
| 手动夹爪协议 | UMI V4.0 |
| 后端 | C++14 本地 HTTP 服务 |
| 前端 | 原生 HTML / CSS / JavaScript |
| 默认端口 | `8080` |
| 默认安装目录 | `D:\UMIDataCapturePlatform` |

## 主要能力

- 海康工业相机、Orbbec Gemini 305 和浏览器 UVC 相机接入。
- 彩色、深度、双红外、点云、手动夹爪和电动夹爪数据采集。
- 双 UMI V4.0 手动夹爪识别、槽位交换、标定补偿、按键、IMU、LED 和参数读取。
- 相机曝光、增益、白平衡、Gamma、锐度、降噪和鱼眼显示控制。
- GCAN 或 ESP32-S3 CAN 串口桥控制电动夹爪。
- 剪刀石头布手势联动和手动夹爪遥控电动夹爪。
- 左右手视觉 + IMU 相对位姿、三维轨迹、夹爪 STEP 模型和闭合动画。
- 统一会话时间基准、历史记录、后台保存队列和会话删除。
- LeRobot、HDF5、RLDS 格式转换和训练就绪校验。
- 一键 Windows 安装包，内置运行时、SDK 和硬件驱动文件。
- 页面心跳、单实例和安全退出闭环，关闭最后一个页面后自动释放全部设备句柄。

## 支持设备

| 类型 | 当前适配 |
| --- | --- |
| 手动夹爪 | UMI V4.0 双手动夹爪 |
| 工业相机 | 海康 MVS USB 工业相机 |
| 深度相机 | Orbbec Gemini 305 |
| 手势相机 | IMX335 或其他 UVC 相机 |
| 电动夹爪 | CAN 电动夹爪，统一行程 `0°~4500°` |
| CAN 接口 | GCAN USBCAN、ESP32-S3 `can_transceiver` |

## 4.3.1 重点更新

- 侧栏伸缩按钮按当前功能页的真实侧栏边沿自动定位，切换页面、展开收起和窗口尺寸变化时保持贴边且不越出屏幕。
- 修正静止夹爪模型缓慢后仰：启动时学习每只夹爪的陀螺仪残余零偏，并在视觉与 IMU 同时静止时跟踪温漂。
- 姿态改为连接或重置时刻的相对方向；限制未严格标定鱼眼视觉对姿态的修正，过滤静止画面的伪旋转。
- 修正 IMU 位移积分重复计算，取消无可信 IMU 尺度时由单目光流凭空生成距离。
- 增加单手静止锁、初始画面特征锚点和原点重定位；前端模型及轨迹增加平滑和静止去抖。
- 新增“空间位姿”页，按左右手独立起点显示视觉与 IMU 融合的相对位置、姿态和轨迹。
- 导入完整 STEP 装配并生成离线 GLB；模型按闭合度同步运动，支持旋转、平移、缩放和动态适配视图。
- 轨迹支持 `1×~8×` 显示倍率，倍率只影响页面观察，录制仍保存原始米制相对位姿。
- 双手同时静止时使用双方 IMU 与视觉作为联合判据，执行协同零速度约束以抑制静态漂移。
- 录制新增 `pose_data/trajectory.csv`，保存四元数、欧拉角、闭合度、质量和协同约束状态。
- 总仓库移动到浅层结构并清除旧驱动副本、运行日志、构建缓存和失效编辑器配置。
- 新增网页客户端登记与心跳；关闭最后一个页面后自动退出后台，浏览器异常结束时超时回收，并提供独立退出快捷方式清理残留进程。

轨迹是视觉惯性估算的相对位姿，不是外部定位系统给出的绝对世界坐标。拿起后回到与重置时相近的视野并保持静止，系统会尝试重定位到原点；需要绝对定位时仍需完成内外参、硬件同步和外部基准标定。
