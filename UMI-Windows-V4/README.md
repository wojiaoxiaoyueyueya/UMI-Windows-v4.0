# UMI Windows V4 数据采集平台

`UMI-Windows-V4` 是当前推荐使用的 Windows 主版本，面向 UMI V4.0 手动夹爪、多相机数据采集和电动夹爪控制。

## 版本状态

| 项目 | 内容 |
| --- | --- |
| 当前版本 | `4.4.0` |
| 发布日期 | 2026-09-02 |
| 操作系统 | Windows 10 / Windows 11 64 位 |
| 手动夹爪协议 | UMI V4.0 |
| 后端 | C++14 本地 HTTP 服务 |
| 前端 | 原生 HTML / CSS / JavaScript |
| 默认端口 | `8080` |
| 默认安装目录 | `D:\UMIDataCapturePlatform` |

## 主要能力

- 海康工业相机、Orbbec Gemini 305 和浏览器 UVC 相机接入。
- 彩色、深度、双红外、点云、手动夹爪和电动夹爪数据采集。
- 双 UMI V4.0 手动夹爪识别、槽位交换、标定补偿、按键、IMU、LED 和参数读取。
- 相机曝光、增益、白平衡、Gamma、锐度、降噪和鱼眼显示控制。
- GCAN 或 ESP32-S3 CAN 串口桥控制电动夹爪。
- 剪刀石头布手势联动和手动夹爪遥控电动夹爪。
- 左右手视觉 + IMU 相对位姿、三维轨迹、夹爪 STEP 模型和闭合动画。
- 统一会话时间基准、历史记录、后台保存队列和会话删除。
- LeRobot、HDF5、RLDS 格式转换；无需填写任务指令，LeRobot 会按真实 action 数据标记训练就绪状态。
- 平台上传：浏览固定转换目录中的 LeRobot、HDF5 或 RLDS 结果，上传至指定任务和场景实例并自动创建待审核记录。
- 一键 Windows 安装包，内置运行时、SDK 和硬件驱动文件。
- 页面心跳、单实例和安全退出闭环，关闭最后一个页面后自动释放全部设备句柄。

## 支持设备

| 类型 | 当前适配 |
| --- | --- |
| 手动夹爪 | UMI V4.0 双手动夹爪 |
| 工业相机 | 海康 MVS USB 工业相机 |
| 深度相机 | Orbbec Gemini 305 |
| 手势相机 | IMX335 或其他 UVC 相机 |
| 电动夹爪 | CAN 电动夹爪，统一行程 `0°~4500°` |
| CAN 接口 | GCAN USBCAN、ESP32-S3 `can_transceiver` |

## 4.4.0 重点更新

- 新增“平台上传”页面：可登录数据训练平台，读取已发布的采集任务和场景实例，并浏览固定转换目录中的输出文件夹。
- 待上传列表支持年月日和 LeRobot、HDF5、RLDS 格式筛选，进度同时显示百分比和已完成文件数。
- 上传仅接受固定转换目录中由本程序生成且结构完整的 LeRobot、HDF5、RLDS 结果，完成后自动创建平台记录并登记为待审核；本地结果不会被移动、删除或改写。
- 自动识别 MP4 视频和 `joints.json`；如果目录缺少关节文件，会生成最小登记文件并在页面显示提示。
- 平台和 MinIO 信息由使用者填写，只保存在本机 `config.local.json`；密码与密钥不会回传网页，Git 和安装包不包含任何预设凭据。
- 统一平台上传页的侧栏、内容区、按钮和筛选样式，并修复该页面左侧状态栏无法伸缩的问题。

## 4.3.3 重点更新

- 三维夹爪改为完整鱼眼相机 STEP 装配，补齐外部壳体和镜头零件；视锥与稀疏特征点从真实镜头前表面向前展开。
- 修正模型坐标映射：红色 X 轴保持不变，IMU 绿色/蓝色安装轴正确转换，位移的上下和前后方向按场景坐标显示。
- 对未标定鱼眼单目位移加入上下/前后主轴串扰抑制，减少上下移动时模型同时前后偏移。
- IMU 启动零偏学习期间检测到明显旋转会立即积分，不再因设备未先静置而长时间保持固定姿态。
- 保留 4.3.2 的双语一键安装、单启动入口、关闭最后网页自动释放设备、完整闭合动画和后台转换能力。

轨迹是视觉惯性估算的相对位姿，不是外部定位系统给出的绝对世界坐标。稀疏点云使用单目特征射线和名义工作距离展示特征分布，不是深度相机的真实测距点云。拿起后回到与重置时相近的视野并保持静止，系统会尝试重定位到原点；需要绝对定位时仍需完成内外参、硬件同步和外部基准标定。
