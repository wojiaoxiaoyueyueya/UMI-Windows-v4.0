UMI 数据采集平台 4.4.1 - 使用说明

1. 双击桌面的“UMI 数据采集平台”即可启动。
2. 安装向导可选择简体中文或 English。默认目录为 D:\UMIDataCapturePlatform；可在目录页浏览非 C 盘位置并新建文件夹。
3. 程序启动后会自动打开 Edge，也可以手动访问 http://127.0.0.1:8080/。
4. 桌面只有一个启动图标。关闭最后一个平台网页后，后台会自动释放相机、串口和 CAN 并退出，无需再点击退出图标或重启电脑。
5. 原始数据默认保存在安装目录的 data_capture 文件夹。
6. 转换结果默认保存在安装目录的 data_converted 文件夹。
7. 首次启动会等待 Windows 完成设备驱动初始化，最多等待 5 分钟。
8. 如果后台没有正常启动，程序会自动打开安装目录中的 startup.log，请把最后一段错误信息发给开发者。
   再次启动时，启动器会自动清理同名的无响应旧后台，避免设备和 8080 端口继续被占用。
9. “空间位姿”页面支持左右手独立视觉惯性轨迹、防穿模闭合动画、相机视锥和稀疏视觉点云；一只手的运动不会改变另一只手的轨迹。
10. 页面中的轨迹显示倍率只影响观察，保存到 pose_data\trajectory.csv 的位置仍为原始米制数据。
11. 4.3.3 使用完整鱼眼相机 STEP 装配，三维视锥从真实镜头正面展开；同时修正模型前后、上下方向和 IMU 启动阶段偶尔不响应旋转的问题。
12. 空间位姿属于视觉惯性相对估计。4.4.1 增加特征补点、前后向光流校验和旋转补偿视差；快速光照变化、弱纹理和未标定鱼眼边缘仍可能造成漂移，开始操作前请静放约 1 秒并按需点击“重置原点”。
13. 拔插相机或夹爪不会关闭后台。主动关闭最后一个网页时约 3 秒后释放设备；浏览器异常结束时连续约 120 秒无心跳才回收后台。
14. “平台上传”页只显示固定转换目录中的 LeRobot、HDF5、RLDS 结果，可按年月日和格式筛选，上传完成后自动登记待审核记录。
15. 首次使用请填写训练平台地址、账号、密码、采集员人员名称，以及 MinIO S3 数据地址、存储桶、访问账号和访问密钥。私有信息仅保存在安装目录的 config.local.json，不随安装包或 Git 分发，也不会以明文回传网页。
16. MinIO 的管理控制台端口不能用于文件上传；请填写管理员提供的 S3 数据服务地址。当前流程会先上传文件到 MinIO，再到训练平台登记待审核记录。

安装程序已经内置并自动注册以下运行库和驱动：

- 海康 MVS x64 SDK Runtime 与 USB3 Vision 驱动。
- Orbbec SDK x64 Runtime（Gemini 305 使用 Windows UVC/WinUSB）。
- GCAN USB-CAN 与 CAN-FD 驱动。
- CH341 串口驱动；UMI USB CDC 使用 Windows 自带驱动。

首次安装会请求一次管理员权限，用于把签名驱动注册到 Windows 驱动仓库。安装结束后无需再手动配置开发环境或 SDK。

测试相机后请关闭 MVS、Orbbec Viewer 等工具，避免它们独占相机。
