# 归档说明

此目录保存 Windows 旧手动夹爪协议版本，用于仍未淘汰的旧硬件兼容和问题复现。

归档版本为 `3.0.0`，对应最终源码提交 `90cf984`。桌面备份 `手动电动夹爪v2备份---windows版本/111.zip` 内嵌的 Git 提交为 `7c0cc4a`；逐文件核对结果完全一致。本目录在该备份基础上还包含一次电动夹爪控制和文档更新，因此源码不缺失且版本更新。

- 不要用于新的 UMI V4.0 手动夹爪。
- 不与 `UMI-Windows-V4` 混合编译。
- 新功能和常规缺陷修复只进入 V4 主版本。
- 需要旧协议时，请在本目录内按原 `README.md` 操作。
- 原始 Git 历史保存在总仓库的 `archive/windows-legacy-history` 分支。
