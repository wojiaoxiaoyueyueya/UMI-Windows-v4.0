Robot Data Capture System

机器人数据采集平台

本项目用于多相机预览、夹爪数据采集、点云采集、数据录制和 LeRobot/HDF5/RLDS 转换。当前运行于 Ubuntu 22.04 x86_64（Linux 版）。项目完全自包含，所有 SDK 在项目内，可直接移植到新电脑。

后端C++17
前端原生 Web
默认端口8080
夹爪槽位left/right/extra

工程结构

目录/文件作用是否提交 Git
src/, include/C++ 后端、设备接入、录制、HTTP API必须提交
frontend/数据看板、采集控制台、说明页面必须提交
tools/数据转换脚本必须提交
third_party_sdk/海康、Orbbec、UMI SDK（项目内自包含）按授权决定
config.json默认端口、数据路径、采集参数提交默认模板
build-linux/编译输出不提交
data_capture/原始采集数据不提交
data_converted/转换后的训练数据不提交
项目完全自包含，所有 SDK 在 third_party_sdk/ 内。移植到新电脑只需拷贝整个目录，不需要安装海康 MVS 客户端或 Orbbec SDK。

从零部署

1. 安装系统依赖

cd linux_ubuntu2204_port bash scripts/bootstrap_ubuntu2204.sh

2. 安装 Python 转换依赖

cd project pip3 install -r requirements.txt

3. 编译运行

bash scripts/build_linux.sh bash scripts/run_linux.sh

启动后访问 http://localhost:8080。不需要设置环境变量，所有 SDK 已包含在项目中。

夹爪槽位为 left、right、extra。UMI 手动夹爪通过 USB VID 自动识别左右手。

移植到新电脑

1. 拷贝整个目录

# 整个 linux_ubuntu2204_port/ 目录拷贝到新电脑 scp -r linux_ubuntu2204_port/ user@newhost:~/

2. 安装依赖并编译

cd UMI-linux bash scripts/bootstrap_ubuntu2204.sh bash scripts/build_linux.sh

3. 运行

bash scripts/run_linux.sh
项目完全自包含。不需要安装海康 MVS 客户端或 Orbbec SDK 到系统目录。

操作流程

  1. 进入采集控制台：/index_old.html。
  2. 点击“重新扫描设备”，确认右上角设备信息和左侧开关都更新。
  3. 打开需要的彩色、深度、红外或夹爪流。
  4. 进入“数据采集”，选择需要录制的数据项。
  5. 点击开始录制，完成动作后点击停止录制。
  6. 进入“数据转换”，选择会话并转换为 LeRobot/HDF5/RLDS。
  7. 回到数据看板检查历史记录。

海康只显示彩色流；Orbbec 显示彩色、深度和红外。设备切换后如果左侧没有更新，先关闭相关预览流，再点击“重新扫描设备”。

数据格式

data_capture/20260602_103000/ ├─ Head-umi/ │ ├─ color_video/ │ ├─ depth_video/ │ ├─ ir-left_video/ │ ├─ ir-right_video/ │ └─ pointcloud_data/ ├─ Left-umi/ │ ├─ color_video/ │ └─ gripper_data/ ├─ Right-umi/ │ ├─ color_video/ │ └─ gripper_data/ └─ metadata.json

视频目录中保存 mp4 和 timestamps.csv。夹爪目录保存 gripper.csv。转换输出位于 data_converted/。

常见问题

页面打不开

确认 ManualGripper 正在运行，默认端口为 8080。如果端口被占用，修改 config.json 中的 server.port。

设备检测不到

点击“重新扫描设备”。海康相机需要 USB 3.0 接口，Orbbec 相机需要正确的 USB 权限。多路 USB 相机建议直连主机。

相机画面黑屏

确认相机镜头已打开，USB 连接稳定。多路 USB 相机建议直连主板 USB 口，避免使用集线器。

转换失败

确认已安装 Python 依赖：pip3 install numpy pyarrow h5py crcmod。只有夹爪数据没有视频的会话会被自动跳过，这是正常行为。

两个手动夹爪识别不到

插入 USB 后确认 /dev/ttyACM* 存在。程序通过 USB VID 自动识别左右手（0x0E01=左，0x0E02=右）。
