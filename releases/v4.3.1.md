# UMI 数据采集系统 4.3.1

当前推荐版本为 `UMI-Windows-V4`。Windows 旧协议版 `3.0.0` 和 Ubuntu 22.04 旧版 `1.0.0` 本次没有修改，继续作为兼容归档保留。

## 本次更新

- 修复 V4 IMU 残余陀螺仪零偏造成的静止模型缓慢后仰。
- 启动和重置后分别学习左右手零偏，并输出相对于当时方向的姿态。
- 单手静止时独立执行零速度约束，缺少可靠尺度时不再生成虚假位移。
- 加入初始画面特征锚点，拿起后回到相近视野并静止时尝试重定位原点。
- 降低未标定鱼眼视觉的姿态权重，过滤静止画面的伪旋转。
- 修正位移积分顺序，三维页面增加模型平滑、轨迹死区和静止去抖。
- 位姿 CSV 新增 `stationary` 和 `origin_relocalized` 状态。
- 修复不同功能页侧栏宽度不一致造成的伸缩按钮错位；按钮现在随当前侧栏边沿、展开动画和窗口尺寸自动定位。

## 安装与启动

1. 下载 `UMI-Data-Capture-Platform-4.3.1-Setup.exe`。
2. 右键选择“以管理员身份运行”，安装到默认 `D:\UMIDataCapturePlatform` 或其他非 C 盘目录。
3. 插入设备，双击桌面的 `UMI Data Capture Platform`。
4. 进入“空间位姿”后，把夹爪静放约 1 秒完成启动校准，再开始移动。
5. 使用结束后关闭最后一个平台页面，或双击 `退出 UMI 数据采集平台`。

完整配置、录制格式和故障排查见 [`UMI-Windows-V4/docs/USER_GUIDE.md`](../UMI-Windows-V4/docs/USER_GUIDE.md)。
