# UMI 数据采集系统 4.3.0

当前推荐版本为 `UMI-Windows-V4`。Windows 旧协议版 `3.0.0` 和 Ubuntu 22.04 旧版 `1.0.0` 本次没有修改，继续作为兼容归档保留。

## 本次更新

- 新增左右手“空间位姿”页面，融合 UMI V4 IMU 和对应相机画面输出相对三维轨迹。
- 使用项目内离线 GLB 显示真实夹爪 STEP 装配，闭合度到端点时模型同步完全闭合。
- 三维视图支持旋转、平移、缩放、动态适配视图和 `1×~8×` 轨迹显示倍率。
- 双手同时静止时启用协同零速度约束，结合双方视觉和 IMU 判断抑制静态漂移。
- 录制会话新增 `pose_data/trajectory.csv`，保存米制位置、姿态、闭合度、跟踪质量和协同状态。
- 工程移动到浅层总目录，清理旧驱动副本、日志、缓存和无效编辑器配置。
- 新增页面心跳、最后页面关闭自动退出、浏览器异常超时回收和单实例保护，退出时完整释放相机、串口、CAN 与 8080 端口。
- 安装后同时提供“UMI 数据采集平台”和“退出 UMI 数据采集平台”两个桌面快捷方式。

## 安装与启动

1. 下载 `UMI-Data-Capture-Platform-4.3.0-Setup.exe`。
2. 右键选择“以管理员身份运行”，安装到默认 `D:\UMIDataCapturePlatform` 或其他非 C 盘目录。
3. 安装程序会部署后台、页面、SDK 运行库、转换环境和硬件驱动。
4. 插入设备，双击桌面的 `UMI Data Capture Platform`，等待 Edge 自动打开控制台。
5. 使用结束后关闭最后一个平台页面，或双击 `退出 UMI 数据采集平台`，确认后台完成设备释放。

源码运行、设备接线、录制格式和故障排查见 [`UMI-Windows-V4/docs/USER_GUIDE.md`](../UMI-Windows-V4/docs/USER_GUIDE.md)。
