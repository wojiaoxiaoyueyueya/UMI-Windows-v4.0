# Windows 安装包

Windows 安装包包含可执行后台、前端页面、Python 转换运行时、SDK 运行库和硬件驱动。由于安装包超过 GitHub 单文件 100 MB 限制，不直接提交到源码目录，而是作为 GitHub Release 附件发布。

下载地址：<https://github.com/wojiaoxiaoyueyueya/UMI-Windows-v4.0/releases/latest>

当前发布版本：`4.4.1`

- [Windows V4 4.4.1](v4.4.1.md)：左右手独立视觉惯性跟踪、鱼眼特征与平移轨迹增强、夹爪防穿模，以及设备拔插不误关后台。
- [Windows V4 4.4.0](v4.4.0.md)：新增固定转换结果校验、MinIO 文件上传、训练平台审核登记、脱敏本机配置，并统一上传页样式与侧栏伸缩。
