# UMI 数据采集系统 4.3.3

当前推荐版本为 `UMI-Windows-V4`。Windows 旧协议版 `3.0.0` 和 Ubuntu 22.04 旧版 `1.0.0` 本次没有修改，继续作为兼容归档保留。

## 本次更新

- 三维页面改用完整鱼眼相机 STEP 装配，补齐相机壳体和真实镜头零件。
- 相机视锥与稀疏视觉特征点从镜头前表面向正确方向展开，并随夹爪模型同步运动。
- 修正模型前后、上下及 IMU 绿色/蓝色安装轴的场景映射。
- 对明显上下或前后运动执行增量主轴滤波，降低未标定鱼眼单目视觉的方向串扰。
- 修复 IMU 启动零偏学习未完成时模型偶尔保持固定姿态的问题。
- 更新 Windows 一键安装包、项目介绍、完整使用手册和版本记录。

## 安装与升级

1. 下载 `UMI-Data-Capture-Platform-4.3.3-Setup.exe`。
2. 关闭 MVS、Orbbec Viewer、串口助手及已打开的平台页面。
3. 以管理员身份运行安装包，可直接覆盖旧版本；安装目录必须位于非 C 盘。
4. 插入设备后从桌面唯一的“UMI 数据采集平台”图标启动。
5. 进入“空间位姿”，静放夹爪约 1 秒后点击“重置原点”，再分别测试左右、上下、前后三个方向。

## 说明

空间位姿仍是单目视觉与 IMU 的相对估计，不是外部绝对定位。弱纹理、快速曝光变化、鱼眼边缘和未完成内外参标定都可能产生漂移；稀疏视觉点仅用于展示特征射线，不是深度测量点云。
