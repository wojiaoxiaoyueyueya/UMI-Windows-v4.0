# UMI Windows V4 4.4.0

发布日期：2026-09-02

## 新增平台上传

- 在本地控制台新增“平台上传”页。
- 可登录数据训练平台，读取已发布采集任务和其下场景实例。
- 只允许从固定转换目录选择 LeRobot、HDF5 或 RLDS 结果，支持年月日和格式筛选。
- 只允许上传固定转换目录中名称和内部结构均通过校验的结果，进度显示百分比和文件数量。
- 数据转换不再要求填写任务指令；LeRobot 缺少 action 文件时仍可输出观测数据集，有真实 action 时继续完整导出并标记训练就绪。
- 上传完成后自动创建采集记录并提交为待审核状态。
- 自动识别 MP4 视频和关节 JSON；缺少关节文件时会生成最小登记文件并给出页面提示。
- 统一上传页和其他控制页的侧栏、面板及按钮样式，修复左侧状态栏伸缩失效。

## 安全与部署

- 平台、采集员和 MinIO 配置由使用者填写，只写入目标电脑的 `config.local.json`。
- 私有配置不进入网页、不提交 Git、也不随安装包分发。
- 平台密码和 MinIO 密钥不会明文回传网页；上传时先写入 MinIO，再向训练平台登记审核记录。

完整配置和操作步骤见 [V4 使用与部署手册](../UMI-Windows-V4/docs/USER_GUIDE.md)。
