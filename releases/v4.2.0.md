# UMI 数据采集系统 4.2.0

当前推荐版本为 `UMI-Windows-V4`。本次发布同时把 Windows V4、Windows 旧协议版和 Ubuntu 22.04 旧版整理到同一个总仓库中，旧版仅用于兼容与历史备份。

## 本次更新

- 重写总仓库首页、V4 版本介绍、页面内项目介绍和完整使用部署手册。
- 正式控制台入口统一为 `/index.html`，数据看板调整为 `/dashboard.html`。
- 清理 V4 中未参与构建的 Linux 海康库、重复 SDK 文件和旧夹爪试验代码。
- LeRobot 转换要求真实动作日志，并补齐任务、IMU、时间戳、终止标记和统计信息。
- HDF5 与 RLDS 明确标记为观察数据归档，避免误判为可直接训练的数据集。
- 安装包内置程序运行库、转换用 Python 环境、相机 SDK 运行库和设备驱动文件。

## 安装

1. 下载 `UMI-Data-Capture-Platform-4.2.0-Setup.exe`。
2. 右键选择“以管理员身份运行”。
3. 安装到默认目录 `D:\UMIDataCapturePlatform`，安装程序不允许安装到系统盘。
4. 首次使用时运行“安装设备驱动”，重启电脑后连接设备。
5. 双击桌面上的 UMI 数据采集平台快捷方式。

详细说明见 [`UMI-Windows-V4/docs/USER_GUIDE.md`](../UMI-Windows-V4/docs/USER_GUIDE.md)。
