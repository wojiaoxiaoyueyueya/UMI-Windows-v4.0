# UMI Windows V4 4.4.1

发布日期：2026-09-08

## 空间位姿与三维模型

- 左右手视觉惯性跟踪改为完全独立，一只夹爪运动、断连或视觉退化时不会改变另一只夹爪的轨迹。
- 增加更密集的鱼眼特征提取、前后向光流校验、旋转补偿视差与方向平滑，减少纯旋转假位移和重获特征后的跳变。
- 优化低速平移响应与前端轨迹采样，缓慢移动时轨迹更连续；每只手仍独立执行静止约束与原点重定位。
- 三维夹爪按照活动零件几何限制闭合行程，减少夹指和连杆穿模。

## 设备拔插与后台生命周期

- 设备拔插和相机 SDK 重枚举造成的短暂心跳中断不再触发后台退出。
- 主动关闭最后一个网页仍会在约 3 秒后释放相机、串口、CAN 和 8080 端口。
- 浏览器崩溃或被强制结束时，后台在连续约 120 秒无心跳后自动回收。
- 海康恢复、设备扫描和夹爪读写线程增加异常隔离，单个设备异常不会终止整个服务。

## 验证

- Windows x64 Release 编译通过。
- 9 项 LeRobot 转换与平台上传自动测试通过。
- 生命周期回归通过：单次心跳后等待 20 秒服务保持运行，发送页面释放后进程和 8080 监听均正常退出。
